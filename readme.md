# Spotter Freight Rate Prediction Challenge

Comprehensive machine learning solution for the **Spotter Machine Learning Engineer Assessment**.  
This repository implements an end-to-end pipeline that trains, validates, and deploys a bagged gradient-boosted decision tree ensemble to predict spot freight load rates (`posted_rate`) across unseen test timeframes.

---

## Executive Summary & Performance

| Model Architecture | Out-of-Time MAE ($) | Out-of-Time RMSE ($) | Out-of-Time MAPE (%) | Out-of-Time R² |
| :--- | :---: | :---: | :---: | :---: |
| **Baseline Heuristic** (`distance × quote_signal`) | $246.02 | $711.80 | 12.11% | 0.7824 |
| **LightGBM** (L1 MAE Objective) | $116.16 | $636.99 | 4.90% | 0.8258 |
| **CatBoost** (MAE Objective) | $125.63 | $639.76 | 5.23% | 0.8242 |
| **Blended Ensemble** (80% LGBM + 20% CB) | **$117.78** | **$637.41** | **4.95%** | **0.8255** |
| **5-Fold Cross-Validation Ensemble (OOF)** | **$86.11** | **$590.79** | **3.90%** | **0.8420** |

- **52.1% MAE Error Reduction** compared to the baseline pricing heuristic.
- Evaluated on a strict **Out-of-Time Temporal Split** (Train: Jan–Aug 2025; Validate: Sep–Oct 2025) to prevent temporal lookahead leakage.
- Final predictions generated using a **5-fold bagged cross-validation ensemble** across all 48,000 labeled development loads.

## Key Data Insights & Resolutions

1. **Negative Cargo Weights**: 292 rows in train and 145 in validation exhibited impossible negative weights (e.g. `-36,559 lbs`). Resolved via `abs(weight)`.
2. **Missing Cargo Weights**: Imputed using equipment-stratified medians (Dry Van: 30k lbs, Reefer: 32k lbs, Flatbed: 28k lbs).
3. **Missing Market Index**: 374 train and 249 validation rows were missing `market_index`. Because `market_index` reflects daily macroeconomic supply/demand, missing values were imputed using the date's cross-lane daily mean.
4. **Geographic Integrity**: Confirmed 1:1 deterministic mapping between city names and GPS centroids, enabling calculation of straight-line Haversine distance, route circuity, and compass bearing.
5. **Weekly & Holiday Seasonality**: Freight rates exhibit a strong 7-day cyclicality (troughs on Sundays, peaks on Wednesdays/Thursdays) with tightening spot capacity into late December (Christmas to New Year).

## Setup & Quickstart Instructions

### 1. Environment Installation
```bash
python -m pip install -r requirements.txt
```

### 2. Run the Full Machine Learning Pipeline
Execute the automated end-to-end pipeline:
```bash
python run_pipeline.py
```
This script will:
1. Clean development data and engineer spatial and freight physics features.
2. Run Protocol 1 (Out-of-Time Temporal Split) and log metrics.
3. Train Protocol 2 (5-Fold Bagged Ensemble) across all 48,000 loads.
4. Generate `validation_predictions.csv` (12,000 loads).
5. Generate `data/december_chart_inputs.csv` (31 loads).
6. Automatically invoke `score.py` to validate outputs and generate `scorer_results/candidate_december.png`.

### 3. Verify with the Official Scorer
To independently verify the prediction outputs:
```bash
python score.py --predictions validation_predictions.csv --december-predictions data/december_chart_inputs.csv
```

Expected output:
```
Validated 12,000 final predictions.
Validated 31 fixed December predictions.
Created chart: scorer_results/candidate_december.png
Final validation metrics are calculated by Spotter after submission.
```

### 4. Regenerate Reports (Optional)
To regenerate both the DOCX and PDF technical reports:
```bash
python -c "from src.report_generator import generate_reports; generate_reports()"
```
